Argus Zone Dashboard

Draw a detection zone on each camera's live view, pick its match mode (any / base), outline color, line width, and alert-border width, set the person-detection confidence threshold, toggle face detection (gaze/attention) on or off, then Save that pane. Use the draw toggle to switch the mouse between drawing the detection zone and an optional light region (amber): when a light region is drawn, the camera reads DARK whenever the average brightness inside it falls below the dark below threshold, overriding the automatic day/night detector. Changes apply on the player within a few seconds (no reboot). The zone shows as a faint green outline on the video feed. any = any part of a person's box in the zone counts; base = only when their feet are in it. Turning face detection off cuts CPU/NPU load; person detection, tracking, and zones keep running. Global settings (log level, default confidence) apply to every stream. Restart services re-reads config.json and mediamtx.yml and restarts mediamtx and all engines without a reboot.

Global settings

warn silences routine output; debug is very verbose but adds per-stage timing lines. A new level applies by restarting each stream's engine, so video pauses briefly. Default confidence applies to streams whose own confidence slider you leave untouched.
